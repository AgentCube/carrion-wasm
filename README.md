# Carrion WASM

A web port of [CARRION](https://store.steampowered.com/app/953490/CARRION/).

**Play:** [https://agentcube.github.io/carrion-wasm](https://agentcube.github.io/carrion-wasm)

> **Note:** Background music is currently disabled for performance and compatibility reasons. This may be addressed in a future update.

## Controls

### In-Game Controls

| Action | Key / Input |
| --- | --- |
| Movement (Slither) | Left Mouse Button (Hold / Drag towards cursor) |
| Grab / Interact / Tear Obstacles | Right Mouse Button (Hold towards target) |
| Roar | Left Mouse Button (Click while stationary) |
| Offensive Ability (e.g. Cobweb / Harpoon) | `Q` or `E` |
| Defensive Ability (e.g. Keratosis / Hydrophobia) | `Spacebar` |
| Echolocation (Locate Hive / Objectives) | `Shift` |
| Pause Menu | `Escape` |

### Menu Controls

| Action | Key / Input |
| --- | --- |
| Navigate Options | Arrow Keys / Mouse Hover |
| Confirm / Select | Left Mouse Button or `Enter` |
| Cancel / Back | `Escape` |
